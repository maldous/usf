|                   |                                              |

This matrix records how the resource lifecycle, relationship, and schema-bound mutation slice is authored against USF semantics with historical `../react` evidence as lineage. USF authors its own runtime; no external runtime/application code is copied, no external source path is mirrored, and it does not claim production, legal, regulatory, eDiscovery, or production-live readiness.

## Behaviour Disposition

| Behaviour                      | Status                                      | USF carrier                                                     | Evidence                                                                                                                                         |
| ------------------------------ | ------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| resource model                 | implemented                                    | `packages/core/src/index.ts`                                    | Resource classifications, resource types, field visibility, lifecycle status, versions, revisions, etags, retention, legal hold, and safe views. |
| relationship graph             | implemented                                    | `packages/core`, `adapters/resources`, `capabilities/resources` | Tenant-scoped relationship records, type validation, cycle denial, required relationship purge block.                                            |
| schema-bound mutations         | implemented                                    | `packages/core`, `capabilities/resources`                       | Unknown fields, immutable fields, hidden fields, restricted fields, and secret-looking values fail closed.                                       |
| lifecycle transitions          | implemented                                    | `packages/core`, `capabilities/resources`                       | Unknown statuses, invalid transitions, self-approval, soft delete, archive, restore, purge, lock, and unlock posture.                            |
| version/concurrency            | implemented                                    | `packages/core`, tests, proof                                   | Version and etag conflict checks plus revision hashes.                                                                                           |
| idempotency/replay             | implemented                                    | `adapters/resources`, `capabilities/resources`, tests, proof    | Tenant-local idempotency keys suppress duplicate side effects.                                                                                   |
| tenant isolation               | implemented                                    | `adapters/resources`, service, tests, proof                     | Tenant A cannot read/list/mutate/link Tenant B resources.                                                                                        |
| PDP authorization              | implemented                                    | `capabilities/resources`, tests, proof                          | Protected resource actions call PDP before mutation or access.                                                                                   |
| retention/legal hold/purge     | implemented                                    | `packages/core`, service, tests, proof                          | Legal hold blocks purge; purge requires eligible status; purged records cannot mutate.                                                           |
| search interaction             | implemented                                    | `capabilities/resources`, tests, proof                          | Soft delete removes safe search projection.                                                                                                      |
| import/export/bulk interaction | partial                                     | `classification=bulk-managed`, guardrail posture, standard      | Concrete resource guardrail path exists; broad bulk resource mutation execution remains deferred depth.                                          |
| files/attachments interaction  | deferred                                    | standard                                                        | File-backed resource semantics are defined; broad attachment route/persistence is deferred.                                                      |
| API/OpenAPI resource routes    | deferred                                    | standard                                                        | Capability posture is proven; broad HTTP resource route surface is deferred.                                                                     |
| React UI/Playwright behaviours | foundation-behaviour-rewritten-from-ui-test | `tests/capabilities/resource-lifecycle.test.ts`, proof          | UI-derived resource mutation behaviours are rewritten as foundation tests. No Playwright is introduced.                                          |

## Non-Goals

No UI implementation. No browser E2E. No live external provider. No production, legal, regulatory, eDiscovery, record-management, or production-live readiness claim.
