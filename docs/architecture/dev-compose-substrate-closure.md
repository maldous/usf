# Dev Compose Substrate Closure

The Dev compose substrate is closed against the current USF service catalogue and generated compose definitions.

The service catalogue remains the authority. Generated compose files are derivative evidence. Dev may use generated compose profiles to exercise service-backed capabilities, but this does not make generated compose semantic authority.

Operator and admin surfaces are represented by current service catalogue ownership, USF-290 service click-through requirements, and safe screenshot or CLI/API evidence where applicable.
