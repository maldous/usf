## Deferred Source-Use Notes

The React portable encrypted archive implementation and Postgres tenant import applier remain lineage only for this slice. USF implements controlled metadata, safety, bounded local retry/resume, provider-transfer fail-closed posture, decompression-bomb denial, rollback/compensation, approval separation, purge, and legal-hold proof now. Production archive formats, production transactional resumable DB appliers, broad HTTP routes, live external transfers, legal/eDiscovery/regulatory export workflows, full parser adapters, production retention services, and live alerting/SIEM integration require separate authority.
